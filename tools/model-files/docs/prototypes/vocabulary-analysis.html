为什么使用 Unicode 标量？

它稳定描述 tokenizer 文件中的原始 piece，不会把 ByteLevel 标记先解码成文本后再改变口径。

例如 Ġ × 128 是 128 个标量、256 个 UTF-8 bytes；经 Qwen ByteLevel 解码后可读为 128 个空格。

注意：“最长”揭示词表构成和异常值，不等于 tokenizer 质量。
