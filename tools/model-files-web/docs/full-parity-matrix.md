## 0. 规则

- **目标**：Web 与原生的用户可见功能、布局、交互和文案尽可能一模一样，以当前原生版为准。
- **例外**只有两类：
  - **平台限制**：必须引用具体的浏览器约束和证据。
  - **用户裁决**：用户明确批准的产品例外。
- 本表来自两次三路只读代码审计（壳层与侧栏 / 文件阅读器 / Tokenizer 与模板），每行引用两侧的 `file:line`。它是**差异清单，不是验收**：每行修复后必须附新证据（单测、E2E 或真实浏览器检查）才能改为 PASS。
