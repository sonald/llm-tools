## 可复跑命令

```bash
npm ci
npm run check
npm run test:e2e
npm run test:e2e:live
node scripts/verify-live-gguf.mjs
git diff --check
```

离线浏览器测试完全拦截 HTTPS；真实仓库 smoke 单独运行。三浏览器都执行三视口几何与 console 断言；Chromium 另把 `390x844.png`、`768x1024.png`、`1280x800.png` 与 `dark-mode.png` 写入 Playwright 临时 output directory（默认 `$TMPDIR/model-files-web-playwright`）。WebKit 截图会由 Playwright 自身注入内联 stylesheet 并制造 CSP console error，因此不把该工具噪声混入应用零告警门禁。

额外隔离验证把候选复制到无 `node_modules`/`dist` 的临时目录，再执行完整门禁；24 个单元测试与 27 个离线三浏览器 E2E 通过。隔离构建与工作区构建的 5 个静态文件 SHA-256 逐项一致；tag 工作流会在 artifact 中附带 `SHA256SUMS`。

## 安全与范围复核

- CSP 脚本、worker、frame、object 默认只允许同源/禁用；`connect-src` 仅放行实测的 `huggingface.co` 与 `*.cdn.hf.co`。实测 Qwen 与 GGUF 内容重定向到 `https://us.aws.cdn.hf.co`。
- 未实现私有仓库、token、SSH、本地文件、Chat、模型推理或完整 GGUF directory。
- 没有完整权重下载回退；所有超限、HTTP 200 Range、错误 Content-Range、无效 UTF-8/JSON/二进制都失败关闭。
- 没有 cookie、本地持久化、遥测或第三方脚本。
